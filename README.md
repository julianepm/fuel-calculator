## Sobre o aplicativo

Aplicativo Android desenvolvido em Kotlin para calcular o custo estimado de uma viagem com base no preço do combustível, consumo do veículo e distância percorrida.
Toda lógica é feita puramente em Kotlin, sem bibliotecas externas ou frameworks avançados, justamente para reforçar os fundamentos, como parte do meu aprendizado de desenvolvimento de aplicativos.

## Tecnologias e conceitos utilizados

Esse projeto utiliza apenas fundamentos do Android tradicional:

- Kotlin
- Activities
- UI com XML
  - TextView
  - EditText
  - Button
- Validação de campos
- Navegação entre telas com Intent
- Passagem de dados entre telas utilizando Intent e Extras
- MaterialToolbar
- Organização básica de layouts e telas
